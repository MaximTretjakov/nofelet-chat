# Nofelet chat

Чат сервис, часть проекта nofelet.

## 🏗 Архитектура проекта 

Проект состоит из четырех основных компонентов:

### 1. Signaling Server (`/cmd/signaling`)
**Реализовано** ✅
- WebSocket сервер для обмена SDP offer/answer и ICE candidates
- Управление подключениями между клиентами

### 2. SFU (Selective Forwarding Unit) (`/cmd/sfu`)
**Скоро начну** 🚧
- Медиасервер для маршрутизации аудио/видео потоков
- Поддержка групповых видеоконференций
- Адаптивная битрейт под клиентские устройства

### 3. HTTP Server (`/cmd/web`)
**Реализовано** ✅
- REST API для управления пользователями и комнатами
- Статический хост для Web клиента
- Аутентификация и авторизация

### 4. Chat Server (`/cmd/chat`)
**В разработке** 🚧
- Чат сервис это часть проекта nofelet
- Присутствует в комнатах p2p и групповых звонках
- Позволяет обмениваться текстовыми сообщениями, картинками, файлами

## 🚀 Быстрый старт

### Предварительные требования
- Go 1.23+
- Для SFU: сервер с поддержкой UDP (для RTP/RTCP)

### Установка и запуск

```bash
# Клонирование репозитория
git clone git@github.com:MaximTretjakov/nofelet.git

# Сборка chat сервера
make build_chat

# Запуск chat сервера
make run_chat

```
